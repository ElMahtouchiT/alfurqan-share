Fichiers pour GitHub Pages

1. Crée un dépôt GitHub public, par exemple : alfurqan-share
2. Ajoute à la racine :
   - index.html
   - alfurqan-preview.png
   - CNAME
3. GitHub > Settings > Pages
4. Source : Deploy from a branch
5. Branch : main / root
6. Dans LWS, crée un CNAME DNS :
   Nom : app
   Cible : TON-UTILISATEUR.github.io
7. Dans GitHub Pages, Custom domain :
   app.alfurqan-quran.be
8. Active Enforce HTTPS dès que proposé.

https://app.alfurqan-quran.be/
